# Natural ou Fake Natty?

#🚀 Explorando os Limites do Realismo Digital com Inteligências Artificiais Generativas 

## 📒 Descrição do Projeto 
Este projeto foi desenvolvido como parte do desafio #LabDIONattyOrNot na plataforma DIO. Ele explora como as inteligências Artificiais Generativas podem ser usadas para criar conteúdos que desafiem os limites do realismo digital. 

## 🤖 Tecnologias Utilizadas
  -IA Generativa **[ChatGPT](https://chat.openai.com)** para criar toda a estética;
 
  -IA Generativa **[Leonardo AI](https://leonardo.ai)** para criar a arte visível do e-book.
