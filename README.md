# Natural ou Fake Natty? Is Aesthetic 💪 

#🚀 Explorando os Limites do Realismo Digital com Inteligências Artificiais Generativas 

## 📒 Descrição do Projeto 

Este e-book de 6 páginas explora a Inteligência Artificial Generativa e a importância de utiliza-la de forma consciente e da maneira certa e boa .

## 🤖 Tecnologias Utilizadas
  -IA Generativa **[ChatGPT](https://chat.openai.com)** para criar toda a estética;
 
  -IA Generativa **[Gamma](https://gamma.app/pt-br)** para criar a arte visível do e-book.

## 🧐 Processo de Criação
    Usei o "ChatGPT" para revisar e saber melhor sobre as IAs Generativas para refinar meu conhecimento sobre a inteligência e usar ao meu favor,
    assim que terminei de fazer a estrutura do meu conteúdo. 
    Também usei a "Gamma.app" para criar as imagens e para meio que criar o e-book com base mo que pesquisei. fui pegando as minhas ideais e montando o e-book.
